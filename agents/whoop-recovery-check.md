# whoop-recovery-check

**Schedule**: 06:30 IST daily  
**Task ID**: `whoop-recovery-check`  
**MCPs**: whoop, todoist, notion

## Purpose

Pull Whoop recovery score at 6:30am. Act on zone:

- **Red (<40%)**: Reschedule deep-work tasks in Todoist to tomorrow. Create P1 alert task.
- **Yellow (40–60%)**: Create P2 pacing reminder.
- **Green (>60%)**: Log only.

All zones log to Notion Claude Sessions with tag `productivity`.
